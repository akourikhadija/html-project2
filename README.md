## How to Work Through This Repo

1. **Study `01-portfolio/` and `02-contact-form/` first.** These were built together live — they show the semantic structure, heading hierarchy, and accessible forms exactly as covered in the session.
2. **Build `03-blog-post/` on your own.** Apply the same patterns without guidance — this is your real check for understanding.
3. **Fix `Challenge/`.** Open the HTML file inside, and find every intentional error — broken nesting, missing labels, wrong element choices, and more. It still loads in a browser, but that doesn't mean it's correct — read the code carefully.
4. **Complete `exercice/`.** This is your main deliverable: a full multi-page portfolio (home, about, blog, contact) built entirely in semantic HTML, no CSS yet. Full instructions are in the `README.md` inside that folder.

---

## Ground Rules

- No CSS in any of these folders yet — the goal right now is clean, meaningful, accessible structure. If a page reads correctly with styling turned off, it's right.
- Every image needs real `alt` text. Every form input needs a connected `<label>`. Every link needs to make sense on its own — no "click here."
- Use semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`) instead of `<div>` wherever one fits.

## A Note on AI

You're welcome to use AI to explain a concept, review your heading hierarchy, or help you understand an error message — not to write the pages for you, and not to solve the Challenge file for you. If you can't explain a line of your own code, don't submit it.
